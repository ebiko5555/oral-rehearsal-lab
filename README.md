# こたえる練習室 — pilot01

修士制作の口頭試問に向けた、約5分・1問だけの学習ゲーム試作。

## 構成

想定質問 → 自分で考える／任意メモ → 段階ヒント → 論文に基づく組み立て確認 → 追質問 → 答え直し → 自己確認と再挑戦。

自由回答の自動採点、模範解答の保存、制作意図の補完はしない。入力しなくても全段階を進める。苦手・手応えは本人が選ぶ。

論文2026-10-07版（本文1–2、8–11、14–15、17–19頁）と口頭試問準備ノート2026-10-13版（1–5頁）の検証済み原稿を使用。本文頁+2がPDF表示頁。資料全文や個人情報は公開しない。質問とヒントは練習案。

独立した静的HTML/CSS/JS。既存のTSUYAリポジトリや鑑賞サイトには依存しない。マイク、録音、カメラ、API、解析、外部フォント、課金なし。CSP connect-src none。

保存はlocalStorageの `oral-rehearsal-lab-pilot01` のみ。進行中1回＋直近8回の記録を保持。端末間同期やオフライン保証はない。初期化はこのキーだけ。

## ローカル起動

`python3 -m http.server 8772 --bind 127.0.0.1`
